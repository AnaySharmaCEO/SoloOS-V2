## 1. Master Alphabetical Glossary

- **Adapter Pattern**: A structural software design pattern that enables classes with incompatible interfaces to collaborate by wrapping their interfaces with an adapter.
- **AI (Artificial Intelligence)**: The simulation of human intelligence processes by computer systems, specifically involving natural-language understanding, pattern recognition, and decision support.
- **AI Orchestration Service**: An application service layer component that sanitizes CRM context, structures prompts, and coordinates calls to external hosted AI providers.
- **BaaS (Backend-as-a-Service)**: A cloud computing model where developers outsource database hosting, user authentication, and serverless compute to managed third-party platforms.
- **Black-Box Testing**: A software testing method where the functionality of an application is examined without knowledge of its internal code structures or implementation details.
- **CDN (Content Delivery Network)**: A geographically distributed network of proxy servers and data centers providing high availability and fast performance for web assets.
- **Client**: A prospective lead that has successfully converted through a closed-won deal and maintains an active or historical commercial relationship with the freelancer.
- **COCOMO (Constructive Cost Model)**: An algorithmic software cost estimation model developed by Barry Boehm that estimates effort and schedule based on software size.
- **CRM (Customer Relationship Management)**: Software systems designed to manage interactions, relationships, and sales pipelines between businesses and their clients.
- **Deal Radar**: An AI-assisted prioritization component in SoloOS that evaluates deal momentum, engagement recency, and value to rank active opportunities.
- **DFD (Data Flow Diagram)**: A graphical representation of the flow of data through an information system, modeling processes, external entities, and data stores.
- **EIF (External Interface File)**: In Function Point Analysis, a user-identifiable group of logically related data referenced by the application but maintained externally.
- **Follow-Up**: A scheduled outreach action associated with an active lead to advance the sales conversation.
- **FPA (Function Point Analysis)**: A standard software engineering sizing methodology that quantifies system capability based on delivered external user functions.
- **Graceful Degradation**: The ability of a software system to maintain essential operational performance even when certain non-critical components (such as an external AI API) fail.
- **HMAC (Hash-based Message Authentication Code)**: A specific cryptographic authentication mechanism involving a cryptographic hash function and a secret shared key.
- **Human-in-the-Loop (HITL)**: A system design governance principle ensuring that automated or AI-generated recommendations require explicit manual human review before execution.
- **IEEE 830**: The IEEE Standard Recommended Practice for Software Requirements Specifications, providing structured guidelines for authoring rigorous requirements.
- **ILF (Internal Logical File)**: In Function Point Analysis, a user-identifiable group of logically related data maintained entirely within the system boundary.
- **JWT (JSON Web Token)**: An open standard (RFC 7519) defining a compact, URL-safe means for securely transmitting claims between parties as a JSON object.
- **Kanban**: An agile visual management method used to track work items and sales opportunities across sequential stage columns.
- **Lead**: A prospective client or sales opportunity under active evaluation and qualification in the sales pipeline.
- **LLM (Large Language Model)**: A machine learning model trained on extensive text datasets to understand, summarize, generate, and predict natural language content.
- **NFR (Non-Functional Requirement)**: A requirement that specifies criteria used to judge the operation of a system (e.g. performance, security, usability) rather than specific behaviors.
- **PCI-DSS (Payment Card Industry Data Security Standard)**: An information security standard for organizations that handle branded credit cards from major card schemes.
- **Pipeline**: The visual progression of sales stages that a prospective client advances through from initial contact to closed-won or closed-lost.
- **Pricing Estimator**: An interactive calculation tool within SoloOS that computes recommended project fee ranges (*Minimum*, *Target*, *Premium*) from scoping inputs.
- **Proposal**: A formal quotation, scope of work, or contract presented to a prospective client specifying deliverable terms and financial compensation.
- **RLS (Row Level Security)**: A database security mechanism in PostgreSQL that restricts row-level access based on the executing user's authenticated identity.
- **RMP (Risk Management Plan)**: A formal document describing how project risks will be identified, evaluated, mitigated, monitored, and controlled.
- **RTM (Requirements Traceability Matrix)**: A grid document linking product requirements from origin through design artifacts and verification test cases.
- **SAQ-A (Self-Assessment Questionnaire A)**: The simplest category of PCI-DSS compliance, applicable to merchants who outsource all cardholder data handling to validated third parties.
- **SCMP (Software Configuration Management Plan)**: A formal document governing version control, baseline configuration, environment promotion, and change control.
- **SDLC (Software Development Life Cycle)**: The structured framework defining tasks performed at each step in the software development and maintenance process.
- **SLOC (Source Lines of Code)**: A software metric used to measure the size of a computer program by counting the number of lines in the text of its source code.
- **SPA (Single Page Application)**: A web application or website that interacts with the user by dynamically rewriting the current web page with data from a web server.
- **SRS (Software Requirements Specification)**: A comprehensive description of the intended purpose and environment for software under development.
- **TLS (Transport Layer Security)**: A cryptographic protocol designed to provide secure communications over a computer network (HTTPS).
- **UAT (User Acceptance Testing)**: The final phase of the software testing process in which real users test the software in realistic scenarios.
- **UML (Unified Modeling Language)**: A standardized general-purpose modeling language in software engineering used to visualize system design.
- **VAF (Value Adjustment Factor)**: A multiplier in Function Point Analysis derived from 14 general system characteristics that adjusts the raw function point count.
- **WBS (Work Breakdown Structure)**: A hierarchical decomposition of the total scope of work to be carried out by the project team to accomplish project objectives.
- **WCAG (Web Content Accessibility Guidelines)**: Technical standards for digital accessibility developed by the World Wide Web Consortium (W3C).
- **Webhook**: An HTTP-based callback mechanism that allows a server application to notify another system asynchronously when a specific event occurs.
- **Weekly Revenue Debrief**: An AI-synthesized weekly executive summary in SoloOS that highlights sales wins, dropped deals, and upcoming pipeline priorities.
